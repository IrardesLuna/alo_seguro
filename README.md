# Alô Seguro

> Verificador de exposição de dados: descubra se seu e-mail ou telefone apareceu em vazamentos conhecidos e saiba o que fazer.

## Sobre o projeto

Muitas pessoas não sabem se seus dados pessoais já vazaram. Quando descobrem, não sabem o que fazer nem a quem recorrer. Além disso, vários sites falsos de "verificação" pedem senha ou cartão justamente para aplicar golpes.

O **Alô Seguro** resolve isso de forma simples:

- a pessoa informa nome, e-mail e telefone;
- o sistema verifica se esses dados aparecem em vazamentos conhecidos;
- o resultado mostra **o que vazou, onde e quando**;
- em seguida, mostra **o que fazer**: trocar senhas, ativar a verificação em duas etapas, falar com o banco, registrar Boletim de Ocorrência e denunciar à ANPD.

O Alô Seguro **nunca pede senha, cartão ou dados bancários** e **não guarda os dados consultados**.
